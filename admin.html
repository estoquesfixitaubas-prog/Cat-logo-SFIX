Ícone do botão de descrição (i)

Por padrão é um círculo com "i". Se preferir, troque por uma imagem sua (logo, símbolo próprio etc). Uma imagem quadrada funciona melhor.

Vale tanto pro ícone padrão (o círculo com "i") quanto pra imagem customizada acima, se ela tiver transparência.

Ícone do app (tela inicial do celular)

É o ícone que aparece quando alguém usa "Instalar app" / "Adicionar à tela inicial" no celular — é um arquivo separado da logo do cabeçalho, então trocar um não muda o outro. Use uma imagem quadrada (recomendado 512x512px), de preferência sem fundo transparente — muitos celulares colocam a imagem dentro de um círculo ou quadrado com fundo branco automaticamente.

Depois de gerar e publicar o pacote atualizado, quem já tinha instalado o app precisa remover o atalho da tela inicial e instalar de novo para ver o ícone novo — o celular guarda uma cópia do ícone antigo no momento da instalação.

Ícone de favoritar (♥)

Botão redondo no canto de cada produto, que a pessoa toca para salvar o item no carrinho de orçamento. Por padrão é o símbolo "♥". Se preferir, troque por uma imagem sua. Uma imagem quadrada funciona melhor.

Vale tanto pro ícone padrão (o coração) quanto pra imagem customizada acima, se ela tiver transparência.

📄 Relatório de produtos

Gera um arquivo .md com nome, código e voltagem de cada produto (em ordem alfabética dentro de cada aba) — pra você conferir no seu sistema o que já existe e o que falta cadastrar. Descrição e múltiplo não entram no relatório.

Marque uma ou mais abas.

📦 Estoque Puma

Exporte o "Relatório de Estoque - Simples" do Puma (Excel/CSV) e importe aqui. O painel cruza automaticamente pelo código de fornecedor (coluna "Refer. Fornec." do relatório) com os códigos já cadastrados em cada produto, e marca cada variante como em estoque ou indisponível. Produtos com saldo no relatório que ainda não existem no catálogo são adicionados automaticamente na aba "🗂️ SEM FOTO", usando esse mesmo código de fornecedor.

Produto/variante que não aparece no relatório importado continua marcado como "em estoque" — só fica indisponível quando aparece no relatório com saldo zerado. Isso ainda não publica nada sozinho: depois de importar, revise o resumo abaixo e use o botão "Salvar alterações" normalmente.

🗂️ Sem foto

Produtos que apareceram num relatório do Puma com saldo em estoque, mas que ainda não existiam no catálogo. Ficam guardados só aqui (nunca são publicados no site) até você colocar a foto, revisar o nome/código e clicar em "Mover para a aba" — só a partir daí eles entram no catálogo de verdade, na próxima publicação.
